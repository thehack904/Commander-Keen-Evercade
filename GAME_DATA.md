# Game Data

Commander Keen Evercade does not include Commander Keen game data.

You must supply the game files from a copy you are legally entitled to use.

For v0.1.0, place each episode's files in:

- `commanderkeen/home/.CommanderGenius/games/keen1/`
- `commanderkeen/home/.CommanderGenius/games/keen2/`
- `commanderkeen/home/.CommanderGenius/games/keen3/`
- `commanderkeen/home/.CommanderGenius/games/keen4/`
- `commanderkeen/home/.CommanderGenius/games/keen5/`

The release leaves these directories empty except for `.gitkeep` placeholders.

Do not redistribute Commander Keen game data as part of this homebrew package.
