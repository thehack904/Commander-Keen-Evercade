# Changelog

## v0.1.0

Initial homebrew release for the original Evercade handheld with EverSD.

- Commander Genius native ARM runtime
- EverSD native launch integration
- 480x272 fullscreen handheld profile
- tested controller configuration
- EverSD control labels updated to describe their actions
- portrait artwork for standard, HD, and 1080 metadata sizes
- 1920x551 game banner
- user-supplied Keen 1-5 episode directories
- no Commander Keen commercial game data
- sanitized/stripped runtime
- no release RPATH/RUNPATH
