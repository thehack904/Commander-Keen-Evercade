# Commander Keen Game Data

This directory is intentionally distributed without Commander Keen game data.

You must provide your own compatible Commander Keen files from a copy of the
game that you legally possess.

## Directory layout

Copy each installed episode into its matching directory:

    games/
    ├── keen1/
    ├── keen2/
    ├── keen3/
    ├── keen4/
    └── keen5/

You do not need to install every episode.

Examples:

- If you own only Commander Keen 1, populate only `keen1/`.
- If you own Commander Keen 1 and 3, populate `keen1/` and `keen3/`.
- Leave directories for games you do not own empty.

The Commander Keen commercial game files are not included with this project.

Do not redistribute commercial game data as part of this package.
